# منصة اللغة العربية — الصف الأول الثانوي الفني (الفصل الدراسي الأول)
## نظام الثلاث سنوات والخمس سنوات والمهني (صناعي - تجاري - زراعي - فندقي)

### 📌 عن المشروع
منظومة تعليمية متكاملة لتدريس ومراجعة واختبار مادة اللغة العربية للصف الأول الثانوي الفني طبقاً للنسخة الرسمية المعتمدة لكتاب وزارة التربية والتعليم والتعليم الفني (طبعة 2024 / 2025م).

---

### ✨ المميزات والركائز الأساسية

1. **الالتزام الحصري بمحتوى المنهج الرسمي:**
   - **القراءة:**
     - الدرس الأول: أسس النجاح في الحياة (أحمد أمين).
     - الدرس الثاني: التعليم الفني والتنمية البشرية (د. إبراهيم شبكة).
     - الدرس الثالث: التواصل الإنساني (د. محمود حمدي زقزوق).
   - **الأدب والنصوص:**
     - وصية أم لابنتها (أمامة بنت الحارث الشيباني) — نثر جاهلي.
     - في الحكمة (لبيد بن ربيعة العامري) — شعر جاهلي ومخضرم مع تنسيق الأبيات الشعرية بدقة.
     - في الرثاء (عبد الله بن رواحة الأنصاري) — رثاء سيد الشهداء حمزة بن عبد المطلب رضي الله عنه.
   - **نحو المنهج المقرّر:**
     - مراجعة عامة وتدريبات الكتاب المحلولة.
     - الجملة الاسمية وأنواع الخبر وتعدد الخبر.
     - كان وأخواتها وتصرفها وجمودها وأحكام اسمها وخبرها.
     - إن وأخواتها ومعانيها وكف عملها بـ "ما" الكافة وأحكام ليتما.
   - **قواعد الكتابة والإملاء:**
     - همزة القطع وألف الوصل ومواضعهما وقاعدة الواو/الفاء.
     - الهمزة المتوسطة وميزان قوة الحركات (الكسرة > الضمة > الفتحة > السكون) والحالات الشاذة.

2. **منظومة التأسيس النحوي التراكمي (خارج المنهج):**
   - مسار مستقل من 12 مرحلة تصاعدية من الصفر حتى الاحتراف الإعرابي.
   - **اختبار تحديد المستوى النحوي (Placement Test):** 15 سؤالاً لتشخيص مستوى الطالب وتوجيهه للمحطة المناسبة.
   - جداول إعراب نموذجية تفاعلية وتحذيرات من الأخطاء النحوية القاتلة.

3. **بنك الأسئلة التفاعلي ومولد الاختبار العشوائي الذكي:**
   - بنك أسئلة تفاعلي بالكامل: تُعرض الأسئلة بخيارات غير محلولة مسبقاً، يختار الطالب إجابته بحرية، وعند الضغط على «تحقق من الإجابة» تظهر النتيجة فوراً (صحيحة / غير صحيحة) مع كشف التعليل وتوجيه القاعدة، مع إمكانية إعادة المحاولة وإعادة التعيين.
   - مئات الأسئلة المتدرجة (اختيار من متعدد، صح أو خطأ، أكمل الجملة) مع فلترة فورية حسب الدرس والنوع والمستوى.
   - مولد اختبارات عشوائية مخصص حسب الدروس ونوعية الأسئلة وعددها.

4. **نظام الامتحانات الرسمية والمحاكاة:**
   - الامتحان النموذجي الشامل لنهاية الفصل الدراسي الأول (مطابق لمواصفات الورقة الامتحانية الوزارية).
   - امتحانات فروع تخصصية (قراءة، نصوص وبلاغة، نحو وكتابة، مراجعة ليلة الامتحان).
   - مؤقت زمني منضبط، خريطة تنقل بالأسئلة، وشاشة مراجعة تحليلية تفصيلية.

5. **ملخصات ليلة الامتحان الموسّعة (المعاني والأفكار والبلاغة والقواعد):**
   - صفحة تفصيلية متكاملة لكل درس تتضمن: المعجم اللغوي المقرّر، الأفكار الرئيسية، مواطن الجمال والاستعارات والأساليب البلاغية.
   - ملخصات نحو وإملاء وافية تشمل: نص القاعدة، خطوات التطبيق الإعرابي العملي، وشواهد ونماذج إعرابية نموذجية محلولة، مع دعم الطباعة الورقية بضغطة زر.

6. **لوحة تقدم الطالب والتحفيز (Offline Local Storage):**
   - حفظ تلقائي لكافة درجات الاختبارات ونسب الإنجاز ونقاط الخبرة (XP).
   - 8 أوسمة وشارات إنجاز تتفتح تدريجياً مع تقدم الطالب.
   - لا تتطلب أي تسجيل دخول أو اتصال بخادم خارجي.

7. **التصميم التحريري وتجربة المستخدم المتقدمة (UI/UX & Routing):**
   - **دعم زر الرجوع بالمتصفح والهاتف (Browser & Hardware Back Button):** نظام توجيه ذكي بالـ History API وPopState يغلق النوافذ المنبثقة أولاً ويتنقل بسلاسة بين الأقسام والشاشات دون الخروج من المنصة.
   - **بطاقات تأسيس النحو التفاعلية بالكامل:** البطاقة بالكامل قابلة للنقر وتفتح في نافذة شاشة عريضة راقية (`max-w-5xl h-[92vh]`) بخلفية معتمة نقية وبدون ضبابية مزعجة.
   - **واجهة ترحيبية أنيقة ومنقحة:** تبرز العنوان الرسمي المعتمد «اللغة العربية للصف الأول الثانوي الفني» وأزرار الإطلاق السريعة دون أي حشو أو نصوص مكررة.
   - **شعار المنصة الرسمي:** يحمل الحرف العربي «م» ومحاذاة رأسية متقنة تمنع أي اقتطاع للنص.
   - دعم كامل للغة العربية RTL وخطوط "Alexandria" و"IBM Plex Sans Arabic" و"Amiri".
   - وضعان لونيان: الوضع النهاري (العاج الدافئ والأخضر الزمردي) والوضع الليلي (الفحم العميق والألوان الدافئة المريحة للعين).
   - مؤثرات صوتية محاكية متناسقة عبر Web Audio API بدون ملفات صوتية ثقيلة.

### 🚀 كيفية التشغيل
يمكن تشغيل المنصة فوراً بأكثر من طريقة:

#### الطريقة الأولى: التشغيل المباشر
- قم بفتح ملف `index.html` في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari) بالنقر المزدوج فقط!

#### الطريقة الثانية: التشغيل عبر خادم محلي
```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام npx serve
npx serve .
```
ثم افتح: `http://localhost:8080`

#### الطريقة الثالثة: النشر على Vercel (Production Ready)
المنصة مجهزة وملف `vercel.json` مهيأ بالكامل لإعادة التوجيه (Rewrites) والترويسات الأمنية:
```bash
# باستخدام Vercel CLI
vercel --prod
```
أو عبر ربط مستودع GitHub مباشرة في لوحة تحكم Vercel دون الحاجة لأي إعدادات إضافية (Zero Configuration).
